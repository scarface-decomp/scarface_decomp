# Legal

This page explains what the project contains, what its license covers and how rights holders can
reach the maintainers. It is not legal advice.

## What is and is not in this repository

* The repository contains source code and tools written by contributors: reconstructed C++ for
  *Scarface: The World Is Yours*, the verifier, the portal and documentation.
* It contains **no** game executables (`Scarface.exe`, `default.xbe`, `game.xbe`), no disc images, no
  game assets (`.rcf` archives, textures, audio, scripts), no leaked or unreleased source code, and no
  debug symbols or link maps from the developer.
* It contains **no** compiler or SDK files. The Visual C++ Toolkit 2003 and the Xbox XDK are Microsoft
  products and are not redistributable. Contributors obtain and use their own copies lawfully; the
  project cannot provide them or help obtain them.
* To check anything against the original game you need your own legally obtained copy of it.
* The portal can copy the files out of your own copy of the game (sounds, textures, models, videos) for
  your personal use. They are written to `extracted/game_files/` on your computer, which is never
  committed. The project does not host or distribute them, and they must not be shared.
* The project does not include, and will not accept, tools for bypassing copy protection.
