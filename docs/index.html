How it works

No magic, no guessing. Just the same compiler the game was built with.

Every game starts as code written by people. A program called a compiler turns that code into the machine code your PC or Xbox runs. Scarface's original code was never released.

So we write it again. Each small piece of the game, called a function, is rewritten in C++ and run through the same compiler the developers used: Microsoft Visual C++ 7.1, from 2003. When the result is identical to the game, byte for byte, that function is done. Nobody has to take anyone's word for it: the compiler decides.

  • Same bytesSame length and same machine code as the original game.
  • Same connectionsEvery jump, call and variable points where the original did.
  • No shortcutsMemory addresses from 2006 can't be typed in as numbers.
  • Real C++No hidden assembly or tricks that just copy the bytes.

    Start helping

    You don't need to be an expert. If you can read a little C++, or want to learn, small functions take minutes. Everything runs on your computer and your game files are never uploaded.

    • Python 3 (free)
    • Your copy of the game
    • About 10 minutes to set up
    1. Install PythonGet Python 3 from python.org. On Windows, tick Add python.exe to PATH on the installer's first screen.
    2. Download the projectOn GitHub, press Code, then Download ZIP, and unzip it anywhere. If you use Git: 
      git clone https://github.com/scarface-decomp/scarface_decomp.git
    3. Add your game filesCopy Scarface.exe (PC version 1.00.2) and/or default.xbe (from the Xbox disc) into the project's binaries folder.
    4. Start the portalOn Windows, double-click START_PORTAL.bat. On Mac or Linux, run sh start_portal.sh. Your browser opens the portal at localhost:8085.
    5. Pick a function and solve itChoose a small one, then press decomp.me. It opens in your browser with the same compiler. Change the C++ until it shows 100%, then paste it back into the portal.
    6. Verify itPress Compile & Verify to record it under your name. That needs the 2003 compiler, installed once from your own VCToolkitSetup.exe: 
      python scripts/setup_msvc71.py VCToolkitSetup.exe
      No compiler? Post your 100% decomp.me link in a GitHub issue and a maintainer will verify it and credit you.

    Questions

    The things people usually ask first.

    What is a function?

    A small, named piece of the game's code that does one job, like checking whether a door is open or adding money to your empire. The game has about 21,000 of them. Many are only a few lines long.

    Do I need to know C++?

    A little helps, but you can learn as you go. The smallest functions are a line or two, the portal writes a starting guess for you, and decomp.me shows exactly which instructions still differ.

    Do I need the game?

    Yes. The project shares only the code people write, never the game. The portal reads your own copy (Scarface.exe 1.00.2 for PC or default.xbe from the Xbox disc) on your computer.

    Does it cost anything?

    No. Python, the portal and decomp.me are free. The 2003 compiler was a free download from Microsoft.

    Is this allowed?

    The repository contains only code written by contributors, under the GPL. It contains no game files, assets or compiler, and it isn't affiliated with the game's owners. The details are in LEGAL.md (not legal advice).

    What about the game's scripts?

    The game also runs compiled scripts (.cso, .dso and .dtr files), written in TorqueScript, a C++-like language. They get the same treatment: a readable version that only counts once it turns back into exactly the original bytes. The first tool, which copies them out of your cement.rcf, is ready; the plan is in SCRIPTS.md.

    I'm stuck. Where do I ask?

    Open an issue on GitHub with the function's address and what you tried. Near misses are useful too.
