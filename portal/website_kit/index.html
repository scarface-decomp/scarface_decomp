How it works

                
Inspired by community matching-decompilation projects such as fnvdecomp.com.

              

            


            

              

                
01 · The original

                
Read the machine code

                
Each function's bytes come from your own copy of the game. All of the Xbox game code can be read, and about a tenth of the PC version's (the rest is encrypted). Functions with the same machine code are grouped, so one match can cover many.

              

              

                
02 · Write it

                
Write real C++

                
Write the function as ordinary C++ (classes, structs and methods), by hand or with the AI helper. Inline assembly and byte tricks are rejected.

              

              

                
03 · Prove it

                
Same compiler, same bytes

                
The portal compiles your C++ with the compiler the developers used, Visual C++ 2003 (cl.exe 13.10). It only counts when every byte matches the original and every call and address points to the same place.

              

              

                
04 · Share it

                
Save it to GitHub

                
Matches are recorded in reports/verified_registry.json and written out as C++ in reconstructed_src/. Maintainers publish them with Sync to GitHub; anyone else opens a pull request. Then they show up on the website.
