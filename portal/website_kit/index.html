Every texture as a picture

                
The game keeps its textures inside its .p3d files: each model, map area and menu carries its own. This writes every one out as a .png into binaries/textures/: the PC's, in a folder named after the file it is in, then what only the other versions have, in their own Exclusive to folders. Where another version has the same picture at a higher resolution (some of the 2006 prototype's world textures, at twice the size) that one is used; the prototype's bigger menu icons are different pictures, so they go in its own folder. INDEX.txt says what came from where.

              

            

            

              
              
              
            

            

          


          

            

              

                
In Blender

                
The game's models and map as scenes made from the files you copied. Open in Blender starts your Blender with the scene already in, and saves it as a .blend you can double-click next time. A downloaded .glb goes in with File > Import > glTF 2.0 (double-clicking a .glb makes Blender try to open it as a .blend: "not a valid Blender file"). Characters come with their skeletons and the game's animations, cameras with their moves, and map areas with the trees, lamps, benches and signs the game places on them. For a single file, use Open next to it in the list above.

How it works

                
Inspired by community matching-decompilation projects such as fnvdecomp.com.

              

            


            

              

                
01 · The original

                
Read the machine code

                
Each function's bytes come from your own copy of the game. All of the Xbox game code can be read, and about a tenth of the PC version's (the rest is encrypted). Functions with the same machine code are grouped, so one match can cover many.

              

              

                
02 · Write it

                
Write real C++

                
Write the function as ordinary C++ (classes, structs and methods), by hand or with the AI helper. Inline assembly and byte tricks are rejected.

              

              

                
03 · Prove it

                
Same compiler, same bytes

                
The portal compiles your C++ with the compiler the developers used, Visual C++ 2003 (cl.exe 13.10). It only counts when every byte matches the original and every call and address points to the same place.

              

              

                
04 · Share it

                
Save it to GitHub

                
Matches are recorded in reports/verified_registry.json and written out as C++ in reconstructed_src/. Maintainers publish them with Sync to GitHub; anyone else opens a pull request. Then they show up on the website.
